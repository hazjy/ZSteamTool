# ZSteamTool v1.1.5

## 新增

- **联机会话**：`opensteamtool.toml` 中 `[onlinefix] env_session = true`（默认开），GUI「联机」页选「宿主会话」启动即可走 Steam 官方大厅。
- **好友广播开关**：`[presence] display = "spacewar"`（默认）或 `"none"`（关闭全部好友广播改写，仅用于排查）。
- **快捷方式富状态**：无需配置。仅用 addappid 的单机游戏，游玩状态会以「非 Steam 游戏」形式广播，好友侧能看到游戏名。
- **家庭共享许可分类**：无需配置。借来的游戏不再被记为已拥有，删改 lua 也不会让它从库中消失。
- **排查脚本**：`tools/diag/`（Steam 更新后的定位链）、`tools/p2ptest/`（双机 P2P 连通性探针）。

## 修复与改进

- 签名表改缓存优先：按客户端 DLL 哈希命中即不联网，启动 49–76 s 降到 0.7 s。
- 毒缓存自愈：缓存表解析出 0 条目或缺必需接口时丢弃并重取一次。
- 下载失败分级：传输故障每镜像重试一次，404 不重试；整条链都 404 才算上游未发布。
- 镜像链补第二活源 `mmxlyo/steam-monitor`。
- 签名表懒刷新：缓存命中但确有函数查不到时后台重取一次，下次启动生效。
- 弹窗：改为中文；`MessageBoxW` 修正中文乱码；按线程 DPI 绘制修正边缘发虚；文案统一书面表述。
- 许可向量扩容后回写长度：注入的 depot 对按长度遍历的逻辑可见，删 lua 能真正摘净。
- 包 0 注入去重、移除时一次摘净：热重载的「先加后删」不再留残影。
- app 返回 0 个 depot 时判失败：不再写入空 depot 配置（原先表现为「入库后瞬间完成 / 0 mounted depots」）。
- 家庭共享与已移除应用的移除保护：lua 变更不再让共享游戏从库中消失。
- 伪造票供体改为 `228980 → 480 → 7` 梯度：AppId 7 缺票时不再整条失败（error 54）。
- 交付前校验票据长度（≥20 字节）与签名边界：坏票不再按正常偏移交给游戏（error 54）。
- 密钥读取改用 `from_chars`、键名兼容 `/`：异常不再从钩子抛进 steamclient。
- ConfigStore 指针改原子读写：修复跨线程裸读写。
- 在线铸造失败时清掉本会话内旧 eticket：不再交付绑定旧 nonce 的票（88500012）。
- 票据扩展数据响应前预检缓冲容量：补丁不再被静默丢弃。
- 报文头部长度改减法比较：消除 uint32 回绕导致的越界读。
- 清单取码异步结果加异常保护：异常不再穿过收包钩子。
- 云待投递队列满时丢最旧一条：对应 RPC 不再永久挂起。
- 库移除通知仅在应用对象存在后发出：不再触发未初始化断言。
- Detours 事务失败即回滚、Attach 失败清句柄：钩子装不上时不再假装已装。
- 进程退出时跳过 DLL 清理：避免在 loader lock 下等待已终止的线程。
- 目录监听改为跨线程取消并等待读取结束：修复退出或重载瞬间的释放后使用。
- 覆盖层、崩溃上报、Steamworks 运行库等伴生进程拉起时不再清除联机会话。
- Steam 安装目录按宿主 exe 定位；两个代理垫片加固（重复加载幂等、按自身目录绝对路径加载、失败不连累宿主）。
